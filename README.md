### 👨‍💻 About Me

I am a **Product Design Engineer** (also known as *Rice Ball* / 饭团). I spend my time exploring the intersections between human-centered product intuition, scalable design systems, engineering execution, and AI agent workflows.

My work focuses on turning ambiguous product ideas into production-ready experiences and building the **Design Harness**—the testing grounds, semantic guardrails, and context scaffolding that allow humans and AI agents to craft high-craft software together.

### 🚀 Featured Projects

Here are a few representative open-source tools and plugins I've designed and engineered:

* 🎨 **[Canvasight](https://github.com/Niall-Young/Canvasight)**  
  An infinite visual canvas and task orchestration MCP plugin. It helps designers and engineers structure, organize, and curate complex tasks before dispatching them to AI agent tools (like Codex).

* ⚡ **[Skill Manager](https://github.com/Niall-Young/Skill-manager)**  
  A lightweight utility for managing and symlinking shared skills across multi-agent AI programming workflows.

* 🔍 **[Design Cursor](https://github.com/Niall-Young/design_cursor)**  
  A Chrome browser extension that lets you inspect web elements and extract them as clean, structured context ready to paste directly into AI conversations.

### 📝 Selected Articles & Deep Dives

In-depth essays on design engineering, vibe coding, and agent context systems:

* 🏗️ **[Design Harness: From `design.md` to Maintainable Context Engineering](https://doc.niallspace.com/ai/posts/design-harness)**  
  An exploration into why standalone prompt files fail in production, contrasting out-of-repo prototyping with in-repo context engineering, and introducing a five-layer architecture: *Intent, Source of Truth, Progressive Disclosure, Constraints, and Feedback*.

* 🧩 **[How to Vibe Code Your Own Component Library](https://doc.niallspace.com/ai/posts/components-dev)**  
  A retrospective across three iterations of building a foundational component library for a Design Harness: shifting from fragile CSS overrides to Figma tokens + MCP, and finally landing on headless Base UI, semantic tokens, and Storybook feedback loops.

* 🤖 **[From an AGENTS.md Guide to AgentsMD-GEN](https://doc.niallspace.com/ai/posts/agents-md-gen)**  
  A pragmatic reflection on instruction budgets and progressive disclosure, turning context discipline into an automated, evidence-backed agent skill.
